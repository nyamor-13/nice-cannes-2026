# Nice → Cannes 2026

Suivi personnel d'entraînement pour le Marathon des Alpes-Maritimes (Nice → Cannes) du **8 novembre 2026**. Objectif 3h45.

Web app statique (HTML/CSS/JS, sans dépendance), pensée mobile-first : jauges de progression, KPI et tendances calculés sur les activités Strava/Garmin, plan de 12 semaines avec objectif physiologique et adaptation à la forme du jour par séance.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | L'application |
| `data-plan.js` | Plan des 12 semaines, zones, archétypes de séances |
| `data-strava.js` | Activités réelles + agrégats hebdomadaires (régénéré automatiquement) |
| `UPDATE.md` | Procédure de mise à jour quotidienne |

Ce dépôt est public pour permettre l'hébergement gratuit sur GitHub Pages, mais son indexation par les moteurs de recherche est bloquée (`<meta name="robots" content="noindex">` + `robots.txt`). Les données affichées sont personnelles.
