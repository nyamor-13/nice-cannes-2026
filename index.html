Synchroniser maintenant

📱 Depuis ton téléphone, ce bouton copie juste la commande — colle-la ensuite dans Claude Code sur ton ordinateur pour qu'elle s'exécute.

Avant de lancer la synchro, vérifie que tout est ouvert
  1. Chrome est ouvert (pas seulement en arrière-plan)
  2. Un onglet est sur connect.garmin.com, connecté à ton compte
  3. L'extension Claude est active dans Chrome
  4. Claude Code est ouvert sur le dossier « Claude Code »

Sans Chrome, la synchro fonctionne quand même — mais avec Strava seul, sans les métriques Garmin.

Colle-la dans Claude Code et envoie. Tu peux aussi lancer la tâche depuis la barre latérale : Scheduled → marathon-nice-cannes-maj → Run now.
